# Data-Driven Sales Insights and Profit Prediction

A data analytics and machine learning project that explores retail sales data, identifies business insights, and predicts profit using Python, Scikit-learn, and Power BI.

## Project Overview

This project analyzes retail sales data to understand sales trends, product performance, regional performance, and profitability. It also applies machine learning models to predict profit based on available features.

## Objectives

- Analyze retail sales data using Python.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify sales and profit trends across categories and regions.
- Build machine learning models for profit prediction.
- Visualize business insights using charts and a Power BI dashboard.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Power BI

## Dataset

The project uses the Global Superstore retail sales dataset.

The repository includes:

- `sales.csv` — Original dataset.
- `cleaned_sales.csv` — Cleaned dataset used for analysis.

## Exploratory Data Analysis

The analysis includes:

- Category-wise sales comparison.
- Monthly sales trends.
- Regional sales and profit analysis.
- Correlation heatmap.
- Sales versus profit visualization.
- Customer segment distribution.

## Machine Learning

The project explores two regression algorithms:

1. Linear Regression
2. Random Forest Regressor

The models are evaluated using Mean Absolute Error (MAE) and the R² score.

The notebook contains the model implementation and evaluation results.

## Power BI Dashboard

The Power BI dashboard provides visual insights into retail sales and profitability.

**Dashboard file:** `Sales_Dashboard.pbix`

To explore the dashboard, download the PBIX file and open it using Microsoft Power BI Desktop.

## How to Run

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```
   
4. Open `sales_analysis.ipynb` in Jupyter Notebook or VS Code.
5. Run the notebook cells to explore the analysis and model results.
